# FleurEPUB

An EPUB reader plugin for Obsidian, built on [foliate-js](https://github.com/johnfactotum/foliate-js) — the FleurPDF experience for e-books.

## Features

- **Reading** — scrolled or paginated flow, single/double column pages, tap zones and wheel paging
- **Typography** — font size / family (preset + local fonts), line & paragraph spacing, page margin
- **Themes** — Light / Dark / Sepia / Green paper themes, applied to the book and the chrome
- **Annotations** — highlights (5 colors), underlines, squiggly underlines, comments with inline cards
- **Sidebar** — TOC, annotation list (HiNote-style cards), full-text search
- **AI assistant** — explain / translate / comment via OpenAI-compatible providers (DeepSeek, GLM, Kimi, Qwen, Doubao, MiniMax...)
- **Export** — annotations to Markdown notes

## Install

Download `main.js`, `manifest.json` from the latest release into `<vault>/.obsidian/plugins/fleur-epub/`, then enable it in Obsidian.
